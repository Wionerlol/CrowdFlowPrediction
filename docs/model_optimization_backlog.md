# 模型优化待办

更新时间：2026-07-06

## 已验证结论

- TaxiBJ 有 73 处非连续时间间隔，旧滑窗会产生跨间断样本。
- 旧时间编码按数组序号推算时槽和星期，无法正确处理真实日期间断。
- AGFormer 使用真实时间戳、连续窗口过滤和门控上下文融合后，测试集平均
  MAE 从公平 Flow-only 基线的 19.8381 降至 16.5350。
- 当前静态输入使用 33 维无泄漏特征；排除了用完整数据计算的 8 维历史流量
  统计，避免验证集和测试集信息泄漏。

## 优化优先级

1. 补齐门控 2×2 消融：Flow、Time、Static、Time+Static。
2. 按真实时间戳和连续窗口规则重跑 LSTM，建立公平排名。
3. 加入动态天气、降雨、温度、节假日前后、高峰和特殊事件特征。
4. 补充中国周末调休信息；当前 `is_workday` 只排除了周末和法定节假日。
5. 优化多步预测头：分时域预测头、编码器—解码器、趋势/周期残差与远期加权。
6. 在融合方案确认有效后扩大 AGFormer：`d_model=48/64`、3 层和更大图嵌入。
7. 最终实验至少使用 3 个随机种子，报告均值和标准差。

## 实验规范

- 训练、验证、测试必须采用相同的时间切分和连续窗口过滤。
- 所有对比固定随机种子、输入/输出长度、优化器、损失和早停规则。
- 每个变体使用独立 checkpoint、TensorBoard 目录和结果标签。
- 动态特征与静态特征通过独立编码器和门控机制融合，不直接无条件相加。
